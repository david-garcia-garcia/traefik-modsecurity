Dynamic config example:

```yaml
logLevel: info                 # trace | debug | info | warn | error
logFormat: json                # json | text
# Plugin logs go to stdout (Traefik process log).
```

Settings table: `logLevel` / `logFormat` → “Plugin logs on Traefik stdout”.
