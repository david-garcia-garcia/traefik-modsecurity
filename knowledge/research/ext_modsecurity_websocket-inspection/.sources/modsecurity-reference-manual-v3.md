ModSecurity is a WAF for HTTP traffic monitoring and real-time analysis. Introduction: protection against attacks against web applications; HTTP transaction logging; monitor HTTP traffic in real time.

Processing phases in the table of contents: Phase Request Headers, Phase Request Body, Phase Response Headers, Phase Response Body, Phase Logging.

Variables and directives are HTTP (REQUEST_HEADERS, REQUEST_BODY, RESPONSE_BODY, RESPONSE_STATUS, and so on). The manual does not define a WebSocket or frame-inspection phase.
